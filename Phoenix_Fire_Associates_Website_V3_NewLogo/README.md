# Phoenix Fire Associates Website V3

A production-ready static website concept for Phoenix Fire Associates.

## Publish on GitHub Pages
Place `index.html`, `styles.css`, `script.js`, and the `assets` folder at the repository root. GitHub Pages should use:
- Branch: main
- Folder: / (root)

The enquiry form opens the visitor's email application and the WhatsApp button uses the Phoenix contact number shown on the supplied website screenshot.
